## Rules
1. **Build in public, explain in private.** Most of your work is private/NDA, so each topic gets a *public* project that shows the same skill, never company code.
2. **Only claim what's true.** Stories use only the verified facts in `../docs/PROFILE_INPUTS.md`.
3. **Every week ends with a deliverable** (repo, write-up, or recorded mock). No deliverable = week not done.
4. **Apply in parallel from Week 3**, not after finishing. Interviews are the best practice.

## Weekly rhythm
- Mon/Tue: learn (theory + docs) · Wed/Thu: build · Fri: write-up + questions · Sat: system-design/mock · Sun: review + plan next week (1 h) and rest.
